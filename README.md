# Bacteriocins in Archaea & Archaeocins in Bacteria

Code and data from paper:

> Bacteriocins in archaea and archaeocins in bacteria
> 
> Romain Strock and Tobias Warnecke<br />
> biorxiv 2026<br />
> DOI: [10.64898/2026.07.27.741052](https://www.biorxiv.org/content/10.64898/2026.07.27.741052v1)

- Data (inputs): `data/`
- Generated outputs: `data/outputs/`
- Notebooks: `notebook/`

## Install

This project uses [uv](https://docs.astral.sh/uv/) to manage Python dependencies.

```sh
uv sync                  # create .venv and install all dependencies
uv run jupyter lab       # launch Jupyter to run the notebooks
```
